# strawberrylove

A tiny arcade game about a lil' bnuy and their love for strawberries. Written in x86-64 assembly using FASM.

## Build

```bash
make
```

## Run

```bash
make run
```

Or run it directly:

```bash
out/sblove
```

## Requirements

- Linux x86-64
- FASM
- Make

## Controls

| Key | Action |
| :---: | --- |
| `wasd` | Move |
| `q` | Quit |
