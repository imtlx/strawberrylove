# strawberrylove

A cute arcade game where you contol a lil' bnuy, explore a grid-based board, and collect straberries.
Written in x86-64 assembly using FASM.

## Build

```bash
make
```

## Usage

```bash
out/bnuy
```

Jump on the board, collect strawberries and have fun!

## Requirements

- Linux x86-64
- FASM
- Make
